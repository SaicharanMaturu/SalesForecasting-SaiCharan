# 📊 End-to-End Sales Forecasting & Demand Intelligence System

A complete end-to-end data science project that predicts future product demand, detects unusual sales patterns, segments products based on demand behavior, and provides business insights through an interactive Streamlit dashboard.

---

## 🚀 Live Demo

🔗 https://salesforecasting-saicharan-npz4kvwxagdpctdf7n9pti.streamlit.app/

---

## 📌 Project Overview

This project was developed as the final internship assignment to simulate a real-world retail analytics system.

The system helps businesses:

- Predict future sales demand
- Compare multiple forecasting models
- Detect unusual sales spikes and drops
- Segment products based on demand behavior
- Support inventory and stocking decisions
- Visualize insights through an interactive dashboard

---

## 🎯 Objectives

- Perform Exploratory Data Analysis (EDA)
- Analyze time-series sales trends
- Forecast future sales using multiple models
- Detect anomalies in weekly sales
- Segment products using clustering
- Build an interactive business dashboard
